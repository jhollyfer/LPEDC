0148 · Union-find: conjuntos disjuntos

Numa turma, quem se conhece, mesmo que só como "amigo de amigo", cai no mesmo sorteio de amigo secreto. As amizades chegam aos poucos, uma por vez, e a qualquer momento alguém pergunta: "Ana e Duda caem no mesmo sorteio?". Você precisa responder rápido e continuar aceitando amizades novas.

O que está em jogo são conjuntos disjuntos: grupos de elementos que não se misturam, em que cada elemento pertence a exatamente um grupo (CORMEN et al., 2024, cap. 19). A estrutura que cuida deles oferece duas operações. A operação acha(x) devolve o representante do grupo de x, um elemento escolhido para responder pelo grupo inteiro. A operação une(a, b) junta o grupo de a com o grupo de b num só. A pergunta do sorteio vira uma comparação: dois elementos estão no mesmo grupo se acha devolve o mesmo representante para os dois.

O union-find guarda cada grupo como uma árvore, e todas as árvores, a floresta, cabem num vetor só. A posição pai[x] diz quem é o pai de x. A raiz é quem aponta para si mesma (pai[x] == x), e ela é o representante. Assim, acha(x) sobe de pai em pai até a raiz, e une(a, b) acha as duas raízes e pendura uma na outra (SEDGEWICK; WAYNE, 2011). No começo, cada pessoa é um grupo sozinho: pai[x] = x para todo x.

Do jeito ingênuo, pendurando sempre a primeira raiz na segunda, a árvore pode virar uma fila comprida, e acha passa a custar O(n). Dois truques resolvem isso.

O primeiro é a união por tamanho. Guarde, em tam[raiz], quantos elementos tem cada grupo, e na união pendure a raiz do grupo menor na do maior. Por que isso segura a altura? Um elemento só desce um nível quando o grupo dele é o menor da união, e então o grupo resultante tem pelo menos o dobro do tamanho. Um grupo só pode dobrar log₂ n vezes antes de passar de n, então nenhum elemento desce mais que log₂ n níveis (LINTZMAYER; MOTA, 2023).

O segundo é a compressão de caminho. Quando acha(x) sobe até a raiz, ele já sabe a resposta para todos os nós do caminho. Então, antes de devolver, faz cada um desses nós apontar direto para a raiz. A próxima consulta a qualquer um deles dá um passo só. Isso tem uma consequência no código: consultar modifica o vetor pai, e por isso acha não pode receber a estrutura como const.

Com os dois truques juntos, uma sequência de m operações custa O(m · α(n)), em que α é o inverso da função de Ackermann, uma função que cresce tão devagar que não passa de 4 para nenhum n que caiba num computador (TARJAN, 1975). Na prática, cada operação custa O(1) amortizado (assunto 0116).

O Cormen chama as operações de MAKE-SET (criar um grupo de um elemento só), FIND-SET (o acha) e UNION (o une). No lugar do tamanho, ele usa a união por posto (rank): cada raiz guarda um limite superior da altura da sua árvore, que só cresce 1 quando duas raízes de mesmo posto se juntam. A garantia é a mesma. O algoritmo de Kruskal (0152) usa essa estrutura para saber se uma aresta fecha um ciclo (CORMEN et al., 2024, cap. 19).

[!WARNING] O representante é a raiz. pai[a] = b arranca o a do grupo; o certo é pai[acha(a)] = acha(b). Testar pai[a] == pai[b] falha com mais de um nível: o teste é acha(a) == acha(b). E tam[x] só vale na raiz.

uf_acha e uf_une, em uniao.c:

int uf_acha(UF *u, int x) {
    int raiz = x;
    while (u->pai[raiz] != raiz) { // sobe até a raiz
        raiz = u->pai[raiz];
    }
    while (u->pai[x] != raiz) {    // compressão: todo mundo do caminho
        int prox = u->pai[x];      // passa a apontar direto para a raiz
        u->pai[x] = raiz;
        x = prox;
    }
    return raiz;
}

bool uf_une(UF *u, int a, int b) {
    int ra = uf_acha(u, a);
    int rb = uf_acha(u, b);
    if (ra == rb) {
        return false; // já estavam juntos
    }
    if (u->tam[ra] < u->tam[rb]) { // ra fica sendo a raiz do grupo maior
        int t = ra;
        ra = rb;
        rb = t;
    }
    u->pai[rb] = ra; // a raiz do menor vira filha da raiz do maior
    u->tam[ra] += u->tam[rb];
    u->grupos--;
    return true;
}

O cliente registra as amizades e mostra pai depois de cada uma:

#include <stdio.h>
#include "uniao.h"

int main(void) {
    const char *nome[] = {"Ana", "Beto", "Caio", "Duda", "Edu", "Fia", "Gui", "Hugo"};
    int amizades[][2] = {{0, 1}, {2, 3}, {4, 5}, {1, 3}, {6, 7}, {5, 7}, {0, 2}};
    UF *turma = uf_cria(8);

    for (int i = 0; i < 7; i++) {
        int a = amizades[i][0], b = amizades[i][1];
        bool novo = uf_une(turma, a, b);
        printf("%s e %s: %s | grupos: %d | ", nome[a], nome[b],
               novo ? "juntou" : "já estavam", uf_grupos(turma));
        uf_mostra(turma);
    }
    printf("Ana e Duda se conhecem? %s\n", uf_juntos(turma, 0, 3) ? "sim" : "não");
    printf("Caio e Hugo se conhecem? %s\n", uf_juntos(turma, 2, 7) ? "sim" : "não");
    printf("Grupo do Edu: %d pessoas\n", uf_tamanho(turma, 4));
    printf("Depois das buscas, ");
    uf_mostra(turma);

    uf_libera(turma);
    return 0;
}
