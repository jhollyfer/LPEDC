0058 · Juntando tudo

O mercadinho anota o fiado num caderno: o nome do cliente e quanto ele deve. Cliente novo ganha uma linha, cliente antigo soma na conta e quem paga fica zerado. O caderno não tem número fixo de páginas, e cada nome tem um tamanho. Os dois problemas, quantidade desconhecida e tamanhos diferentes, são exatamente o que o módulo ensinou a resolver.

Comece por onde o caderno mora. Ele precisa durar o programa todo e crescer conforme chegam clientes, então não cabe num frame da pilha; mora no heap (assunto 0053). Quem decide quando ele some é o próprio programa, no fim (CELES; RANGEL, 2002).

Cada nome digitado chega numa variável temporária, que vai ser reaproveitada na próxima leitura. Para guardá-lo de vez, a função duplicar pede ao malloc (assunto 0054) um bloco do tamanho exato, strlen(nome) + 1 bytes, e copia o texto para lá. O + 1 é o lugar do '\0' (BACKES, 2013, cap. 11). "Bia" ocupa 4 bytes e "Dona Cida", 10; nenhum espaço é desperdiçado.

O caderno em si são dois vetores paralelos: nomes, com o endereço do nome de cada cliente, e centavos, com o quanto cada um deve, na mesma posição. Quando os dois enchem, a função crescer dobra a capacidade dos dois juntos com realloc (assunto 0055), sempre por um ponteiro temporário, para não perder o bloco se o pedido falhar (CELES; RANGEL, 2002).

O vetor nomes tem tipo char **: é um vetor de char *, e cada item aponta para um bloco de tamanho próprio. É a mesma forma da matriz dinâmica com linhas de tamanhos diferentes (assunto 0056) (BACKES, 2013, cap. 11).

A novidade do programa está no parâmetro de crescer. O realloc pode mudar o bloco de lugar, então a função precisa mudar o ponteiro nomes do main. Pela regra do assunto 0049, ela recebe o endereço desse ponteiro. Como nomes é char **, o endereço dele é um char ***: três estrelas, uma para cada salto até a letra (FEOFILOFF, 2009, ap. F). O mesmo raciocínio dá int ** para o vetor centavos.

Os valores ficam em centavos, guardados em int. Um double não representa 0,10 com exatidão, e somas de muitos valores acumulam erro de arredondamento; inteiros não têm esse problema. R$ 12,50 vira 1250, e a conversão para reais acontece só na hora de mostrar.

Por fim, a limpeza segue a ordem do assunto 0056: primeiro cada nome, depois os dois vetores. Os dois vetores paralelos funcionam, mas são um remendo. A struct do módulo 08 junta "nome e saldo" numa coisa só, e um vetor de struct cliente precisa de um realloc só.

[!WARNING] Liberar só nomes vaza todos os nomes: cada nomes[i] tem seu malloc, dentro de duplicar. São 2 malloc no começo e 5 nomes (os realloc só trocam um bloco por outro), então liberar faz 5 + 2 free. Confira com valgrind ./programa a linha All heap blocks were freed.

{{exemplo}}

Chegam seis anotações: Dona Cida (R$ 12,50), Seu Jorge (R$ 8,30), Dona Cida de novo (R$ 4,70), Bia (R$ 20,00), Tonho (R$ 3,15) e Rosa (R$ 5,60). São 5 clientes, então o caderno cresce de 2 para 4 e de 4 para 8. Depois Seu Jorge paga tudo:

{{ideia}}

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

// Cópia de uma string num bloco do tamanho exato.
char *duplicar(const char *texto) {
    char *copia = malloc(strlen(texto) + 1);
    if (copia != NULL) {
        strcpy(copia, texto);
    }
    return copia;
}

// Dobra a capacidade dos dois vetores paralelos. Recebe o ENDEREÇO dos
// ponteiros do main (char *** e int **) porque o realloc pode mudá-los.
int crescer(char ***nomes, int **centavos, int *cap) {
    int nova = *cap * 2;
    char **mais_nomes = realloc(*nomes, nova * sizeof **nomes);
    if (mais_nomes == NULL) {
        return 0;
    }
    *nomes = mais_nomes;
    int *mais_centavos = realloc(*centavos, nova * sizeof **centavos);
    if (mais_centavos == NULL) {
        return 0;
    }
    *centavos = mais_centavos;
    printf("(caderno cresceu: %d -> %d clientes)\n", *cap, nova);
    *cap = nova;
    return 1;
}

int buscar(char **nomes, int qtd, const char *nome) {
    for (int i = 0; i < qtd; i++) {
        if (strcmp(nomes[i], nome) == 0) {
            return i;
        }
    }
    return -1;
}

// Soma uma compra na conta do cliente; cria a conta se ela não existe.
int anotar(char ***nomes, int **centavos, int *qtd, int *cap, const char *nome, int valor) {
    int i = buscar(*nomes, *qtd, nome);
    if (i >= 0) {
        (*centavos)[i] += valor;
        return 1;
    }
    if (*qtd == *cap && !crescer(nomes, centavos, cap)) {
        return 0;
    }
    char *copia = duplicar(nome);
    if (copia == NULL) {
        return 0;
    }
    (*nomes)[*qtd] = copia;
    (*centavos)[*qtd] = valor;
    (*qtd)++;
    return 1;
}

void liberar(char **nomes, int *centavos, int qtd) {
    for (int i = 0; i < qtd; i++) {
        free(nomes[i]); // cada nome é um bloco
    }
    free(nomes);        // depois o vetor de ponteiros
    free(centavos);
}

int main(void) {
    int qtd = 0;
    int cap = 2;
    char **nomes = malloc(cap * sizeof *nomes);
    int *centavos = malloc(cap * sizeof *centavos);
    if (nomes == NULL || centavos == NULL) {
        free(nomes);
        free(centavos);
        return 1;
    }

    const char *quem[] = {"Dona Cida", "Seu Jorge", "Dona Cida", "Bia", "Tonho", "Rosa"};
    int valor[] = {1250, 830, 470, 2000, 315, 560}; // em centavos
    for (int k = 0; k < 6; k++) {
        if (!anotar(&nomes, &centavos, &qtd, &cap, quem[k], valor[k])) {
            liberar(nomes, centavos, qtd);
            return 1;
        }
    }

    int i = buscar(nomes, qtd, "Seu Jorge"); // Seu Jorge pagou tudo
    if (i >= 0) {
        centavos[i] = 0;
    }

    int total = 0;
    for (int k = 0; k < qtd; k++) {
        printf("%-10s R$ %3d.%02d\n", nomes[k], centavos[k] / 100, centavos[k] % 100);
        total += centavos[k];
    }
    printf("Total na rua: R$ %d.%02d\n", total / 100, total % 100);

    liberar(nomes, centavos, qtd);
    return 0;
}
// Saída:
// (caderno cresceu: 2 -> 4 clientes)
// (caderno cresceu: 4 -> 8 clientes)
// Dona Cida  R$  17.20
// Seu Jorge  R$   0.00
// Bia        R$  20.00
// Tonho      R$   3.15
// Rosa       R$   5.60
// Total na rua: R$ 45.95
